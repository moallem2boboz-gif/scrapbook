OUR SCRAPBOOK  (everything here stays on your computer)

HOW TO OPEN
  Double-click index.html, or open this folder in VS Code and use the
  "Live Server" extension (right-click index.html > Open with Live Server).

FOLDERS
  index.html      the page structure
  css/            the looks:  shared.css, night.css (Laufey), rose.css
  js/content.js   ALL the words, lists, quiz questions and photo paths  <- edit this
  js/script.js    how everything works (pages, themes, music, quiz)
  images/         every photo, as normal files

CHANGING THINGS
  - Text, love notes, quiz, timeline, songs:  open js/content.js
  - A photo: replace the file in images/ (keep the same name),
    or add a new file and point to it in js/content.js
  - Dates and captions for memories: the "memories:[" list in js/content.js

NOTES
  - The fonts load from the internet. Offline, the page uses plain fallback fonts.
  - The in-page Edit mode (tap the small heart on the cover 3 times, or Shift+E)
    saves only in that one browser. For permanent changes, edit js/content.js.
  - Nothing here is uploaded anywhere. To give it to her, zip the folder
    and send it, or copy it onto a USB stick.
